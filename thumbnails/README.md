# Thumbnails

Name each image after the row **ID** from the library, then hover the entry in a dropdown to see it.

* `ST0599.jpg`: a style (Style Atlas)
* `KC0021.png`: a known character (Character Atlas)
* `HP0003.webp`: a hand pose
* `LOC0042.jpg`: a location (Setting Atlas)

Small square images (256 to 384 px) are enough. No restart is needed; the list refreshes every few seconds.

`convert.ps1` turns every `.jpg` in the folder into a clean medium-quality JPG (it needs ImageMagick, `magick`).
